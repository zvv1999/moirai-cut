# 居家学习插画的独立部件

来源：Creative Tim / IRA Design，MIT许可见 `LICENSE.txt`。原图为
`ira-design/ira-illustrations` 的 `SVG/Examples/bg5-1.svg`，归档版本
`e2e7f9f6aaff3170526a67a2434732e07407fb1e`，原始矢量保留为 `original.svg`。
源文件哈希、部件和图像边界见 `parts.json`。

八个SVG按原源图语义分离：空间衬底、书架、植物、沙发、吊灯、柔光、包、人物与电脑。
保留原配色和路径，没有生成新的AI位图。PNG以完整1200×900画布等比渲染，再按各自
透明边界加4像素空边裁剪。`bounds` 是每个部件在完整画布中的位置，用于可复现地重组。

Moirai Cut 样式 `style-study-20260928-learning` r3 把这八个部件绑定为独立资源槽，
支持选择、运动、位置、缩放和资源替换。图像内部路径在编辑器中不是原生图形节点；
需要改变内部颜色/造型时编辑SVG后重新渲染、导入并替换对应资源。不能将资源层可编辑
宣传成任意矢量路径在工作台可编辑。

`source-render.png` 和 `reassembled.png` 用于对照源图与八层复合结果。独立栅格化在
边缘上产生少量舍入差异：深色底平均通道差0.0392/255，最大25/255，不能称逐像素相同。
透明边界已保留；这些图片是可编辑动效的部件，不是循环视频或GIF。

动效、语义事件及整体布局保存在Rust样式库，本文不声明美学验收通过。
