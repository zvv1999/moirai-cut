# 居家学习插画 v2：小尺寸主体与层次

这是 `learning-room-v1` 的局部派生，属于同一个模板方向，不新增模板数量。
来源仍为 Creative Tim / IRA Design，MIT 许可完整保留在 `LICENSE.txt`。
原始文件为 `ira-design/ira-illustrations`，归档提交
`e2e7f9f6aaff3170526a67a2434732e07407fb1e` 内 `SVG/Examples/bg5-1.svg`。
未修改的源矢量保存在 `original.svg`，源文件和归档哈希记录在 `parts.json`。

v2 保留空间衬底、书架、植物、沙发、吊灯、柔光、包、人物与电脑八个资源层。
人物和电脑在 SVG 内以可见底部中心放大 1.30 倍，保留座位接触和灯下留白；
增强沙发坐垫与内凹面的层次、书架内腔和植物叶片的明暗，给白电脑增加轻薄冷色边缘。
原有淡紫背景、蓝紫人物与冷青色身份保持。没有生成 AI 位图，也没有增加脸部、文字或小装饰。

PNG 仍使用 1200×900 透明完整画布等比渲染，再按可见边界加 4px 裁切。
`bounds` 是完整画布的裁切位置，`alphaBounds` 是可见像素边界，不能当作 SVG 坐标。
人物缩放已经写进 SVG，新模板只需按新 bounds 放置，**不能再次乘 1.30**。
v2 reader 的可见范围是 x489–736、y258–598，底部与 v1 同为 y598。
与吊灯可见底部之间留有 25px 源画布空间。人物裁切图由 200×271 变为 256×349。

已人工查看 1200、390 和 110px 场景宽度的浅底/深底前后对照，
390px 时人物和电脑的主次明显改善；110px 仍只能辨认整体学习场景，
细节太小，不构成推荐使用尺寸或跨输入成片验收通过。完整场景以390px设备预览中至少180px宽作为本轮起测建议，仍要检查具体内容。
仅在720p输出上量260px不能证明手机显示够大；更小时应减少次要层或换简洁学习图标。

资源层支持选择、位置、缩放、动效、隐藏和替换。内部矢量路径在工作台不是原生可编辑节点；
内部改色/形状需修改所附 SVG 并重新渲染导入。`reassembled.png` 是八层静态复合，
不表示视频动效或听感已验收。

五个变更PNG现已导入，保存为 `style-study-20260928-learning` r4；八资源绑定完整。
