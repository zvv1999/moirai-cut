## r3基础结论

`style-study-20260928-learning` r3 已完成一轮可编辑素材和生产链路验证。它把原始 MIT IRA 场景拆成 8 个有语义的透明素材：背景、书架、植物、沙发、灯、灯光、包和人物/电脑。每个素材都能作为独立图片层替换、禁用和选中，样式保留原始配色与路径，没有新增未经授权的 AI 像素。

这次验证证明了素材拆分、资源槽、组级入退场和工作台编辑闭环；它没有证明内部 SVG 路径已经成为原生可编辑节点，也没有证明插画在任意真实背景上都能达到90分。

## 规则和实现

- 8 个素材以透明 SVG/PNG 资源导入，保留原始来源和许可证文件。
- 8 层作为同一事件组统一入场120ms、退场60ms；局部 settling 只在120–200ms内完成，不声明持续循环或 GIF 动画。
- 资源槽可以逐层替换或禁用；模板默认、应用覆盖和本次禁用不改变模板定义。
- 建议最小场景宽度约260px（720p），目标事件长度至少0.8秒；短事件优先降低装饰或跳过插画。
- 8 层是可替换的图片层，内部 SVG path 仍然是位图/矢量资源整体，不是编辑器中的8组路径节点。
