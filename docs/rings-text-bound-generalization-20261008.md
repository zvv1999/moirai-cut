## 保存的通用规则

一个原生 `headline` 文字宿主与四个原生椭圆叶层：主/副深色描边、主/副金色墨线。四圈都依附精确的原生文字实例，`referenceBounds=text_box`、`followMotion=true`、中心叠放。原生文字暖白、深色细描边，最大两行。编译和实际工程保留文字、关键词/短语标注及圈的独立旋转、缩放、透明度关键帧。

- 主圈宽为实际文字框的 1.50 倍，高为 1.65 倍；副圈为 1.55 / 1.70 倍。
- 两轴每侧各加 12 个 720 设计画布像素。`Application.scale` 会缩放此保护量。
- 圈从 1.06 倍收束到 1，主/副分别从 −4°/+4° 收到 −2.5°/+2.5°；160ms 入场，100ms 退场。避免从小于文字的圈穿过字角。
- 文字 120ms 淡入并轻上移；当前输入由 Agent 选择完整重点、自然短语、位置、行宽、比例、保持时间与保护区。这些不写成模板中的台词、词下标或固定秒分支。
- 规则依赖原生文字的实际尺寸。烧录在原片里的字、人物与物体仍由 Agent 检查其画面范围，不能冒充可测量文字宿主。

字段契约与实现见 [文字尺寸绑定](text-size-binding-design.md)。尺寸绑定不保证任意椭圆都能容纳字角；旋转、内沿、长宽比例、入场过冲与当前画面留白仍必须实测。

## 仍需改善的效果

英文实拍上的小尺寸黄线和字形力量仍偏弱；两行短英文容易变成接近圆形的徽章，与中文长词的横向双圈观感有差异。相邻事件的单行/两行切换仍直接。继续探索通用线宽/文字对比与更紧凑的双圈比例时，须同时回归字角内沿和所有已通过长度，不能只修 June 一个位置。

窄画面空位无法同时留出清楚文字和舒适边距时，应选择更紧凑的其他样式，而非把这个方向扩展到所有镜头。还需要中文真人背景与更多复杂画面、连续实时观片及原声试听，之后才有依据讨论 90 分接受。
