原版主要由一圈平面表框、四个刻度和双针构成。本轮增加真实可编辑的几何层次：外壳厚度、上沿窄高光、珐琅面、内圈分隔、暖白表盘斜边、十二个径向刻度、双针窄高光和铜轴心。原生叶节点从 11 个增至 28 个，加一个合成根组；无外部位图。`style-clock-detail-candidate-20260929` 仅作为同家族参考，没有改写或另计数量。

四个主刻度比八个细刻度更强；短针为蓝灰色，长针为暖铜色。两根指针及各自圆头、高光使用相同的角度曲线和共同中心，通过 `R(v)-v` 的位置补偿保持同轴。长针在 135ms 内完成定性的轻转，短针轻微回正；没有数字、倒计时或真实时刻含义。

根组在约 100ms 内淡入并完成轻微缩放、位移回正，指针略晚停稳；最后 45ms 先合成再整组淡出。词时间没有延长。新造型先经原生工作台黑、白、棋盘背景预览后，使用 `baseRevision=4` 对同一 ID 保存到 r5，再由保存版生成 Application 和实际生产图。源定义、保存前快照、CAS 回执与请求均保留。
