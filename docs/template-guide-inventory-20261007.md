## 保存与效果验收

1. 保存前回读每条ID和revision，核对草稿源定义SHA；若他人有编辑，重新核对，不能用旧快照覆盖。只新增usageGuide，不改造型、运动、绑定或资源。保留原定义、CAS回执与新版本。
2. 保存后原生inspect并比较投影，说明仅指南与revision的变化；旧应用评分不继承新revision。工作台抽查阅读型、原生图标、图片资源及多角色组合的指南编辑与回读。
3. 冻结版本后Agent读取指南，保存输入分析来源、单次参数差异及原因；允许按case调整。字形、位置、行宽变化后重新测量，具体画面失败不自动改模板。
4. 每方向覆盖短词/长词/两行、快慢事件、无合适语义负例、明暗/复杂背景和重要画面保护。只声称已验证的语言与画幅；新画幅需独立预算。
5. 最终检查真实导出稳定帧及完整入退场、文字覆盖、遮挡、编辑性和连续原声。连续播放/试听只能在实际执行后记录，不用抽帧或PCM一致冒充听感通过。
6. 原样式精确Application评审遵循现行协议的样例数量；不同位置的Agent应用分别保留。定制组合另记，不把多个应用最高分合并成整款的保证。≥90且无阻断才进入20款交付计数。
