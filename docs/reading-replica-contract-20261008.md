# 同文装饰副本与成片阅读诊断

2026-10-08。承接 `template-reading-replica-design.md`。此文档记录执行状态，不提升既有样式评分或最终验收状态。

## 契约

`Composition.readingReplicas` 与动态素材 `Definition.readingReplicas` 使用同一关系：`{elementId, primaryId}`。副本为文字且角色显式是 `decoration`，主层为非装饰文字；禁止缺失引用、自指、多主层、链式依附及不兼容内容绑定。声明不改变内容生成、时间编排、几何或动效。

`POST /templates/production/{batchId}/items/{itemIndex}/reading-diagnostic` 从冻结生产项读取编译实例及排版测量，核对当前成片 SHA 和样例指纹。调用方提供观看宽度、最小字号、最大行数以及具体实例的稳定起点、观察到的稳定时长和要求的阅读时长。稳定时间是调用方观察，不是机器视觉结论。

同一内容的两个实例还须具有同一来源事件、相同最终文字、相符的实测行文并能唯一配对。主层字号、行数、溢出和稳定区间覆盖通过后，副本才能免除独立停留预算。副本的实际排版与画布边界仍需检查。边界采样不证明遮挡或视觉竞争不存在，接口不会设置最终审美或试听通过。

## 工作台

- 样式图层的“应用规则”与模板组合的“主读文字与装饰副本”均可编辑关系；不会自动切换语义角色或改外观。失效引用保持可见并可清除。
- 生产成片和评审证据中均提供“阅读检查与同文副本”，按需读取具体文字实例；稳定时段默认留空，不能把整个显示区间当作稳定期。
- 更换批次、样例、成片 SHA、样例指纹、检查标准或观察预算时，旧诊断立即隐藏。迟到或已取消的请求不能恢复旧结果。
- 排版测量、停留预算、同文身份和视觉检查分别显示；数据不足保留“不完整”。
