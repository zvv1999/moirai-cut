# 试映内容与应用历史闭环（2026-10-07）

## 逐句译文

新增正常表单 `translation-content.tsx`。原生 `/plan` 提供当前字幕正文、时间和词范围；用户逐句填写译文，启用时固定该份原生字幕范围，防止重新分段后译文错配。已有译文时原文校正与字幕拆合暂锁定，明确提供“清除译文并解锁分段”；重点词与同排标注仍可编辑。工作台不自动翻译，也不改变原声音词级时间。

译文通过实时预览、生产、JSON 导入导出、会话记忆、历史保存/恢复完整传递。对应数组与字幕数量的校验在 Rust；样式包含 translation 图层时可渲染译文。

## 共用与按设计的素材设置

新增 `sample-resource-bindings.tsx`：共用资源设置是主入口，每个设计的覆盖放在可展开的“按设计单独设置”中。两个作用范围分别存储，包含 `enabled:false`，恢复默认时只移除该范围的覆盖，不会扁平化或覆盖另一范围。

`ProductionCreate` 的 snapshot、恢复、JSON、session、预览和生产分别保留 `resourceBindings` 与 `designResourceBindings`。应用配置改变导致投影模板 ID 更新时，只迁移该设计的键，保留完整槽设置；不留下旧设计键或静默删槽。失去对应设计/槽的设置会显示并提供明确移除按钮。生产预检改用原生 `/samples/validate`，由 Rust 解析两级优先关系。
