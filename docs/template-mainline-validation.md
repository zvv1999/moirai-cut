## 2026-09-23 重点词与逐字字幕的独立预览

## 2026-09-23 固定入退场时间模型

元素新增可选 `motionTiming`，原有定义默认保持归一化缩放。Rust 在生命周期处理之后映射元素自身的动作关键帧：固定入场/退场秒数，中间停留随实例时长变化；极短实例按比例压缩两阶段，合并重合边界，不延长字幕和语音。语音逐字高亮和关系生成的状态通道使用各自的事件时钟。修正了零退场长度时可能把淡出扩散到整个停留期的边界处理。

效果工作台与整片模板的动效面板均可切换时间模式、编辑入退场秒数和阶段边界，应用原生入退场预设。新增通用 `/templates/elements/envelope` / AI `apply_template_element_envelope`；动态资产 `envelope` 操作复用同一 Rust 实现。预设生成普通可编辑透明度和入场关键帧，保存时保留完整阶段映射。

## 当前收敛方向（2026-09-23）

主线为：选一个效果 → 编辑元素与动效 → 用真实内容预览 → 保存模板 → 应用到视频。素材库提供创作原料，模板工作台负责可复用效果，智能剪辑负责在真实内容中选择和调度。参考复刻作为创建入口，批量生产作为单模板稳定后的操作，关系/约束/JSON 保留在高级能力中。

用户明确的时间边界：模板不保存某条成片的绝对时间轴。模板包含内容绑定、样式、动效与相对触发/结束规则；TTS 或原声的实测词时间和事件提供具体时刻，应用时生成可编辑时间轴。相对动效关键帧属于模板，实例开始/结束秒数属于应用结果。固定入场/退场时长与随内容伸缩的停留时长需要明确区分，不能把整段效果机械拉伸到配音长度。

以下问题仍未验收通过，不能用后续局部测试替代整体完成：

- 草稿近似动画已移除，画布播放入口连接真实试映；准确动效依赖实际输入与渲染，尚未实现即时的统一动态预览。
- 局部效果模板与整片编排的界面边界仍需整理，当前分组导航不等同于用户无需理解内部结构就能完成创作。

- 技术发布不等于审美验收；功能样例不授予 90 分，也不证明模板库与参考产品的质感一致。
