# 通用画面避让规则

2026-10-09。修正“每遇到一个遮挡就调整一个模板”的工作方式。模板保存风格、图文依附与运动；画面标注提供保护范围；Rust 的同一约束求解器决定本次应用位置。

## 执行规则

1. 将整组效果的范围加上留白，要求其位于画面安全边界内。
2. 人物、产品、原字幕、关键图示和其他叠加元素均可作为硬保护区。输入应是它们在整个效果期间的移动范围并集，不是某一帧的框。
3. 从画布边界和保护区边界推导可行位置，以输出像素位移最小为优先。默认不再尝试七个固定中心，也没有模板 ID、输入原句或演员坐标分支。
4. 只移动本次应用的整体位置，保留字号、比例、旋转、图文关系、运动、时机及素材构图。找不到位置就跳过本次叠加或换构图重新检查；不自动缩字、不放宽保护区、不改模板默认位置。
5. 没有完整证据时，结果只是待预览方案。严格模式不返回可应用结果，避免把静态矩形不相交当作整段安全。

`rust/crates/footage/src/templates/placement_policy.rs` 是独立几何求解器。保护区按效果包络扩张后成为禁止的中心区域；这些区域的边界与当前中心的投影组成有限候选集合。完整检查该集合可以找到轴对齐平移问题中的最近可行位置。最多 64 个保护区，返回最近 16 个可行位置及当前位置；截断的是返回结果，不是搜索。横竖画幅使用实际像素距离，等距时按坐标确定顺序。

## 接口与证据

沿用 `POST /api/footage/templates/dynamic-assets/placement-advice`，AI 使用 `advise_dynamic_asset_placement`。`placementAdvice` schema 与 `placementAdviceCapabilities` 暴露同一能力。

- `policy.safeInset`：每侧归一化安全边距，0–0.25，缺省 0。
- `padding`：效果外额外留白，0–0.25。
- `policy.requireFullCoverage`：缺省 false；true 时必须提供完整效果和保护区覆盖声明。
- `protectedRegions`：整段需要保护的空间并集。
- `protectedRegionsCoverage`：`unverified` 或调用方声明的 `whole_effect`。
- `sample`：当前完整内容标注；提供动效包络时必填。
- `motionEnvelope`：包含精确的 `application`、`sample`、未裁切的 `bounds`、`coverage`（`partial` / `all_rendered_frames`）、`includesDecorations` 和证据 `reference`。应用或内容不同会拒绝复用旧包络。

完整包络应包含所有可见图层在入场、停留、退场每一个输出帧的范围，以及描边、阴影、依附和文字尺寸绑定。部分包络只能增加已知占用范围，不能缩小已有静态估计。只提供几帧或漏掉装饰时保持未验证。此版本使用整个效果的保守并集，因此可能放弃按时段精细求解后能利用的空间。

旧包络不能总是直接平移。例如以画布中心缩放的复合组，会把叶层的 0.2 位移变成 0.24；直接复用旧范围可能漏判。`translation_check` 检查坐标归属，遇到整组非单位缩放/旋转、布局重排或外部锚点等情况，改变位置后必须重测候选；原位置的完整证据仍可使用。不会为迁就求解器修改已有动画执行方式。

`decision` 分为 `propose`、`skip`、`needs_evidence`。`geometryCheck` 区分静态估计、部分包络及调用方提供的完整包络。所有响应的 `placementCertified` 都是 false：位置算法执行了约束判断，但没有自动识别画面，也没有独立验证调用方的测量声明。`search.complete` 仅表示平移几何搜索完整，不等于生产、视觉或听觉验收通过；显式 `candidates` 仅检查调用方给定列表。

## 工作台与历史

工作台增加安全边距和完整证据要求，候选统一使用黄色虚线及“待预览方案”。无解和缺证据都不提供应用按钮。换素材时保留通用规则及留白，内容、时段或构图改变时使旧保护框失效。

应用历史在顶层保存 `placementPolicy` 和 `placementPadding`，与 `protectedRegions` 一起恢复并显示差异。旧记录缺省字段不被补写，保留原有幂等身份。模板定义和既有评分不因位置建议改变。

## 仍需补齐的自动化

现有工作台只提供静态框选；正常导出已采集文字排版事实，但尚未自动采集所有图层含描边、阴影的完整包络，画面保护区也没有自动跟踪。此次实现的是可执行的统一位置规则、证据门槛与编辑历史接入。完整自动防遮挡仍须将全视觉测量及画面跟踪接入，不能宣称已经无人值守跑通。
