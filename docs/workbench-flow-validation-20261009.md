## 修复

- Rust `Plan.contentIssues` 提供缺少重点的结构化诊断，保留原警告兼容；前端按模板和输入分组，默认收起分段列表，提供直达对应段落的按钮。
- 修改内容后旧确认失效；保留当前标注继续生成时，跳过缺少重点的花字。Rust 不再将普通语义、字幕、视频事件的整句原文兜底为关键词；明确的 Keyword 事件仍可提供关键词文本。
- 草稿和普通应用的结果绑定完整提交内容。换标题、重点、素材或绑定后，旧结果标为上一版；历史任务与当前表单分开说明。
- 工作台应用现有模板使用 `previewOnly: true`，生成独立可编辑工程和 MP4，不递增模板库版本。显式保存模板及 Agent 新模板生产保留各自语义。
- 恢复已保存内容时，空语义段从 Rust 验证结果补齐；保留人工分段和仅事件输入，多输入按 inputId 匹配，异常响应不会部分替换表单。
- 素材增加搜索；同步提交锁防止重复点击；普通视频生成不再提示“入库”。
