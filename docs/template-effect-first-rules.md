# 以模板效果为先的通用规则

2026-09-29。落实用户要求：变量可以建模，优先交付好看的可复用模板。本文是设计约束与验收标准，不代表以下建议均已实现。

## 当前执行原则

以[模板泛化与 Agent 应用规则](template-generalization-policy.md)为准：模板定义风格与约束，Agent负责单个case的应用调整。下文固定参数对照是历史实验方法和证据，不要求不同输入永远共用相同坐标，也不把实验数值升级为全库默认。

## 三层边界

1. 模板保存视觉设计：字体层级、配色、描边、底板、装饰关系和相对动效。先提供设计师调好的默认值，再开放高级参数；不能把一堆自由变量交给用户自行拼出效果。
2. 内容应用提供文字、重点词、语义短语、声音对齐事件、画面保护区。具体词下标、某个人脸坐标、绝对起止秒数属于这次输入，不能写死成模板规则。
3. Rust依据模板与应用输入生成实例；Web只负责编辑、测量和呈现。自动识别与人工标注必须区分；无识别证据不能声称智能避让。

## 交付顺序：先完成视觉设计，再提炼可调规则

用户再次确认：变量建模服务于模板效果。每轮的交付对象是一个可观看、可复用的设计，不是字段数量。以下是设计与验收约束，不表示已新增自动评分或参数联动能力。

1. 明确用途：正文阅读、关键词强调、情绪花字、图解说明分别定义视觉主次；同一图标放在不同位置不自动成为不同风格。
2. 完成默认效果：先调好字体、轮廓、配色、图文比例、留白与运动，默认应用就应成立。比较候选时保持输入、画面和触发时机一致。
3. 提炼有效变量：只开放确实有用的大小、行宽、强调程度、装饰开关等控制；高级编辑保留叶层能力。哪些字段联动必须由明确契约实现，不能仅靠控件名称暗示。
4. 换内容复验：保存设计不变，更换短词、长词、多行、快慢声音和明暗背景；覆盖无关键词负例。失败时修正规则或明确适用范围，不能逐句写死位置和换行。
5. 用成片决定保留：检查稳定帧、完整入退场和实际阅读效果；记录视觉缺陷。导出、几何避让、模型字段和测量通过只是基础证据，不替代质量验收。

### 灯泡方向的视觉判断（2026-09-30）

本轮重新查看已有 `bulb-headline-20260929/2-hold.png` 与 `bulb-reading-phrases-20260929/1-hold.png`，没有修改样式或产生新成片。

- 花字版：暖黄灯泡、奶油色粗字与棕色轮廓具有统一配色；图标位于文字上方，整体倾斜提供轻松的强调感。两行长词仍有辨识度，但当前证据是黑底稳定帧，不能据此认可复杂实拍中的尺度与动效。
- 正文辅助版：小灯泡与底部字幕构成同一阅读区域，视觉更克制。它承担语义提示，而不是强强调；不能把附着正确当作花字效果已达标。
- 后续对照应分别在同一真实输入中比较花字强调与正文辅助，保留共同的语义触发，不在每句正文旁强加灯泡。重点检查大图标是否抢人物焦点、长词是否削弱字重，以及短事件是否看得清。

两者目前均不能因本次抽帧检查获得90分；本轮不增加合格模板计数。

## 最少但有视觉意义的变量

| 变量组 | 应控制的视觉结果 | 通用规则与边界 |
| --- | --- | --- |
| 文字层级 | 正文、重点词、花字各有主次 | 限制同屏强调层数；重点词放大不能挤掉正文；阅读标签默认左对齐，标题可单独设置 |
| 色彩角色 | 字色、强调色、轮廓、底板和装饰一致 | 使用同一风格配色角色；不要让独立图标任意混入另一套颜色。配色联动需后续实现，不能将文档当作已有能力 |
| 尺寸与留白 | 长短文字都保持可读与呼吸感 | 按文字实际边界附着底板和装饰；区分字距、内边距和元素间距，禁止针对一句话写死宽度 |
| 构图关系 | 装饰与它说明的文字形成一组 | 优先使用现有相对定位/依附能力；人物、原有字幕为保护区。没有合适位置时减少装饰，不以随意角落放置作为通过标准 |
| 动效节奏 | 入场干脆、停留可读、退场利落 | 复用现有相对动效和入退场时长；TTS决定实例时间。短事件应简化动效，不能机械加速全部关键帧 |
| 内容负荷 | 密集词段不拥挤、不反复抢眼 | 短语边界独立于强调范围；长内容换行或拆显示单元。降级策略需显式定义，不得暗改原声时间 |

已有字段优先复用；只有重复出现、无法由现有组合表达的视觉问题才新增原生字段。每个新增字段必须同时有默认值、人可编辑入口、AI契约和真实成片证据。

## 效果验收

每个候选先用相同输入比较，避免换视频掩盖样式缺陷；胜出后换短词、长词、快慢语速及不同画面背景验证。逐项记录文字可读性、风格一致性、构图、动效和适配证据。多画幅未经验证不宣称全画幅通用。

技术校验与审美评审分开：能导出、字段齐全、关键帧正确不自动得到90分。已验证的局部应用分数也不代表所有输入。早期原片导出存在64个44100Hz样本（约1.45毫秒）的固定音频偏移。2026-09-29改用整容器解码后的新原片导出已通过零偏移全片相关性及四时段延迟搜索；旧失败证据保留，未试听，不代表所有编码格式通过。详见style-delivery-status.md的原片音频修复记录。

## 行长平衡与对齐正交

自动适配文字区域时，左/中/右对齐只决定每行文字靠哪一边，不应决定是否能避免过短尾行。`fitTextRegion`现在在字号拟合完成后，对三种对齐共用已有测量分行器；保持贪心分行所需行数，不为均衡增加一行，不改变选定字号。显式换行形成独立段落，有效的`layoutPhrases`仍限制可断开边界。

此规则只作用于自动适配区域的渲染路径；不会向输入文案写入换行或调整声音时间。字形测量与分行属于Web渲染职责，Rust继续拥有内容分段、样式和布局约束。旧左/右对齐自动布局可能重新分行，这是本次预期的可见变化；固定手动段落仍保留。均匀行长并不等同语义分析，紧密短语仍需正确内容标注。

## 紧凑阅读宽度与内容短语分开验证

实拍长句仅将正文 `region.width` 从 .78 收到 .64，保持中心、区域高度、字号38.4、最多两行及装饰规则不变。长句能从接近全幅的横条变成紧凑两行，短句显示保持；这是该风格的通用阅读预算，不是针对某个句子的换行指令。

宽度本身不能理解语法。实测出现“because / of …”断开后，在输入 `layoutPhrases[].wordSpan` 标注完整因果短语11–18，模板完全不变，得到“For the June solstice, / because of the tilt of the earth,”。标注来自Agent对原文的分析，绝不把这些词下标存为模板规则。保存候选 composition-bulb-reading-width-20260929 v1。

两步对照分别保存于 Downloads/bulb-reading-width-20260929 和 Downloads/bulb-reading-phrases-20260929。多行图文依附已有实拍抽帧证据，但底部身体/手势遮挡与实时阅读感受仍需评审；不等于全画幅通用或90分验收。

## 避让不能脱离阅读预算

2026-09-30侧栏实拍实验：同一24%宽、32px、最多5行的阅读样式，原生placement-advice依据人工保护区选左/左/右，人物手势得以保留。但长句出现五行、孤词和语义短语回退。因此该布局不作为完整字幕的通用默认，技术上的clear只表示所建模矩形无碰撞。

下一步候选评价必须同时考虑阅读宽度/行数、短语可容纳性及画面保护；不能为了避让无限压窄或缩字。短提示可以使用侧栏；完整正文若不存在兼顾阅读与保护的位置，应报告冲突或选择经过验证的其他构图，不能静默把不合格候选当成功。该联合评价是后续要求，本轮未新增已实现能力声明。证据：Downloads/checklist-side-reading-20260930/review.html。

## 短语保护是通用规则，效果仍是验收对象

2026-09-30补充：模板可选 `segmentation.preserveLayoutPhrases`，输入提供内容短语范围。原生分段在预算及硬边界允许时保留短语整体，显式字幕范围保持优先。模板中不保存句子、词下标或某次TTS绝对时间；缺少标注时保持原自动分段。

同一侧栏样式在两份真实输入共13句复测，开启前跨句的短语在开启后完整，1–3行、32px，PCM相同。但视觉分量偏小、三处速度警告未消除。因此这项建模是改善复用的基础，不是新模板，更不能替代90分效果验收。后续视觉迭代应在统一构图候选上提高阅读分量，覆盖短句/长句/关键词/无关键词，再决定是否成为默认。

### 关键词触发与退出边界分开（2026-09-30）

分层清单r2复用既有timing字段：keyword_start开始，endAnchor=cue_end结束，maxSeconds=3。短词可继续保持到本句结束，中长词不被强行延长；完整字幕与音频时间不变。这是样式的统一生命周期选择，不是针对“完成”延长某个绝对秒数。minSeconds本身不承担延长逻辑。所有依附装饰采用同一边界，避免文字/图标先后失配。若关键词跨字幕边界，原生cue_end会拒绝，调用方需选择适用边界，不得静默越界。

六份输入验证：中文短词.32→1.56秒，中长词.92/2.24秒保持，实拍重点1.02→1.90秒；清单1.25倍与文字边界偏移一致，两个无重点负例无装饰。该规则改善短词展示机会，但不代表任何短句均有足够停留：词本身在句末仍受句末约束；最多3秒也可能截断很长的句子。以最终观看结果评审，不把字段设置当质量达标。

### 内容短语不能代替指定行尾

`layoutPhrases` 是内容侧的不可轻易拆开范围，属于输入，不是模板的固定换行文本。优先标注最小必要词组（专名、数字单位、完整词语）；需要完整语义短语时再扩展，不应为了复刻一次换行把普通修饰语都绑成大块。已有渲染器在预算内保留词组，再在词组之间做实测行长均衡，因此过宽的有效词组会合法地阻止更均衡的分行。

排查长短行时先核对标注，再判断是否需要改变风格宽度/字号。只因单句7/3不美观就更改全局排版器或缩小所有字号，会伤害其他正常输入。词组保护与行长均衡冲突时，应如实记录取舍，不承诺同时总能满足。

### 同一强调样式的有限候选摆放

青色弹字r2复测使用同一scale .75与左右上方候选，由原生placement-advice对输入的人工保护区选择。三个实拍与一个中文音频得到左/右/左/左，Alex的太阳图干扰在所查关键词中点消除。样式与事件时机不变，16词段实测1–2行、40.30–56.25px。该结果支持“先定义有限构图候选，再用内容保护区筛选”的复用方式；不支持任意画面自动适配。保护区识别、连续运动安全和主观视觉质量需分别验证，几何clear不能直接授予90分。

### 双层文字先统一排版预算

双层花字r7前后两层区域、字体参数相同，但描边分别3.5/6px（scale .5应用），实际文字测量包括描边，导致11/16事件得到不同字号。r8仅将粉色底层描边改成主层宽度，保留粉色偏移、旋转和组透明度；16事件两层字号及行分布完全一致，约45.09–50px。适用于同字形偏移轮廓的设计；故意不同字形或字号的层次仍可独立配置。

本次不需要增加共享测量字段，也不把相同文字自动强制绑定。若未来要保留不同描边仍同步字形尺寸，需要显式的共同适配契约并覆盖编辑/AI/导出；不能把本次参数一致误称为已实现通用跨层测量。

### 可复用规则与效果验证分层（2026-09-30）

便签这轮只调整保存样式的两层 `textAlign=left`，沿用 `backgroundPadding`、`maxLines`、`spatialRelations.referenceBounds=text_box`、`followMotion` 等已有契约。纸面跟随排版后的文本，胶带依附实际文字框；词时间仍来自输入。无需为每个视觉现象新建一个字段。

复测工具 `scripts/templates/produce-style-rule-review.mjs` 接受一个 JSON 配置路径：
- `output`：机器本地的证据输出绝对路径。
- `name`：批次名称。
- `policy`：原生 placement-advice 的 `application`、`padding`、`candidates`；所有输入共享。
- `fixtures`：`{sample, protectedRegions}` 数组。`sample` 保留素材 ID、转写版本和内容标注，保护区属于输入画面。

工具先核对全部输入版本及候选可行性，再提交可恢复的幂等预览批次。位置筛选与模板投影由 Rust API 完成，脚本不复制业务算法。输出应用、请求、批次 ID 供复查；它不自动打审美分，也不把不同位置算成不同模板。没有可行候选时保留失败，不自动缩到不可读或覆盖重要画面。

### 多层材质的退场按视觉整体合成

便签的纸面、偏移纸影与胶带构成一个视觉对象。若每层单独降低透明度，后面的纸影会透过逐渐透明的纸面，退场过程会改变材质颜色。对于这种设计，使用已有分组合成能力：`composite=true`、`separateInstances=true`，把淡出 treatment 作用到组；胶带局部透明度保持 .9，原有文字与纸面运动保持独立可编辑。

该规则不要求所有装饰都编成一组。只有需要保持层间遮挡关系的视觉对象采用整体透明度；有意错峰离场的元素仍保持独立。关键词实例分别合成，避免把不同时间事件绑定为一个贯穿全片的组。动态检查应取最后一个透明度为1的关键帧计算保持时间，不能假定倒数第二个关键帧就是淡出起点：原生编译器可能在淡出区间插入采样点。

### 装饰细节依附装饰本身

便签r8材质候选中的胶带高光使用两个原生矩形，依附`paper-tape`的layout边界、overlay锚点与局部offset，并继承其运动。胶带本身仍依附headline的实际text_box。因此正文换行只改变最上游文字测量，细节不再重复保存另一套文字偏移，也不需要针对长词调坐标。

纸影采用较小偏移与恒定局部透明度，再与纸面、高光一起进行组淡出。局部透明度表达材质，组透明度表达整个对象的生命周期，两者可组合。该候选仍是平面图形设计；添加两条细线不等于真实纸张纹理，最终是否保留应由成片对照决定。

实测修正：首次r8导出暴露了依附链缺陷，高光漂在胶带旁边。`relationships::text_attachments` 原先仅为直接text_box关系登记渲染期测量修正，layout跟随者只有编译期运动。现由Rust把确切文字实例与锚点修正沿followMotion的layout链传递，保持原生编辑关系，不用逐句坐标补丁。新增回归覆盖乱序多级图形链、重复时间实例及关闭跟随的边界；需要以修复服务后的成片为依据，首次错误导出保留作失败对照。

### 阅读停留属于编排策略

便签r8短词实验复用既有`template.visualRhythm.minDisplaySeconds=.8`，不在独立样式里写死某个词的时间。keyword_start默认生命周期在原事件之后利用空隙补足停留；较长原事件不缩短，视频结束及maxSeconds仍截断，显式endAnchor优先。Rust现在限制额外停留不得越过下一个关键词开始（含相同offsetSeconds），不更改原事件自身可能已有的重叠。

0.8秒是本次编排候选，不是所有风格的强制值。短事件密集时可能无法满足；这不是可读性通过保证。工作台组合模板的“高级设置→断句与编排→最短展示（秒）”使用既有字段，AI可读取同一模板策略。此实验改变了Application投影后的模板编排，因此不能引用独立样式Application评审协议登记分数，也不能继承r7的83分。

### 先分开字号与行宽，再考虑整体缩小

奶油底签同一r7应用试验：scale从.55恢复.65，通过Application.textWidths.headline=.24独立约束行宽。四输入共享左右位置候选与宽度，实际16段均44.2px、1–2行，没有以缩字适配，几何及实测阅读检查都通过。前一版整体缩小仅37.4px。因此在此边角阅读场景，先调整文字区域与换行，比进一步缩小整组更合适。

文字行宽并不保证任意长词都不缩字，仍需实测与最小字号门槛。工作台试映已有“主样式文字行宽”控件，本轮验证URL恢复、刷新和传给原生API的参数；没有添加重复字段。位置保护区仍是人工输入标注，不把结果描述为自动理解画面。

### 图标花字的短事件优先保留稳定呈现

灯泡花字r2统一采用80ms入场、30ms组退场，替代120ms/60ms，保留原缩放、旋转、光芒展开与图文依附。四种实测声音事件和同一应用对照中，文字仍46.2px、1–2行，短词更早稳定且较晚淡出，长词不改变视觉造型。复用现有motionTiming即可表达，不需要针对“灵感”设置例外。

这只是这款轻量图标花字的默认节奏，不是所有模板的固定规则。0.34秒事件仍然很短，不能仅凭缩短入退场宣称充分可读。实拍背景覆盖、完整观片和审美评分尚待完成。证据见bulb-cross-snappy-20260930。

### 画面内不等于留白充足

灯泡花字实拍长词的几何候选可用，但28%行宽、右候选中心85%时文字仍贴近边缘。应用统一收为24%行宽、中心84%，保持短词46.2px，允许长词有限缩至42.13px（门槛40px、最多两行），取得较好的边缘留白。两份有重点词的实拍和无重点负例复测；参数属于可复现应用配置，未改样式库r2或新增字段。

该例说明候选通过之后仍需看最终画面，且字号与留白存在取舍。不能为追求不缩字让长词贴边，也不能无限缩字；越过阅读门槛应拒绝候选并换构图。此规则不是任意输入或画幅的通过证明。
