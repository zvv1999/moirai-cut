# 模板批量生产验收（2026-09-17）

目标：由 Agent 利用素材库设计并自动批量生产可复用、可编辑的模板，形成类似开拍的花字、贴纸、动效与画面编排效果。

当前交付已具备这条链路，最终核验包含 11 款原创模板、22 个成片和 22 个独立可编辑工程。这里的 11 款包含不同用途、字幕行为及画幅的设计，不等于 11 个完全不同的风格家族，也不把库中的参考种子条目计为已审片的原创模板。

## 使用入口

- Agent：按 `.agents/skills/moirai-cut-template-production/SKILL.md` 读取素材、检查参考、设计模板，然后调用 `produce_templates`。
- CLI：`bun run templates:produce --designs /absolute/path/designs.json`。
- 查看结果：本地 `/templates/production`，每个成片下方的“编辑样例”打开对应时间线。
- 复用模板：本地 `/templates` 中选择模板，将资源槽与新工程素材绑定后检查并应用。

Agent 负责设计和审片；Rust 负责状态、约束、编排、验证和入库；浏览器负责实际渲染。当前没有额外的独立文生模板服务，批量生产仍由当前 Agent 发起。修改样例工程不会自动修改可复用模板。

## 验证结果与边界

- Rust 库测试 117 通过；默认忽略的 AAC 集成测试已单独通过。可选 NAS 发布基准未运行。
- MCP 素材、生产编排和工作台测试 15 通过；文字排版与着色测试 9 通过；Web 类型检查通过。
- 22 个最终 MP4 本次重新验证 SHA-256 并完整解码；实际音轨与源音频的既有对比为 16 kHz 下零最佳匹配延迟。该测量不等于音效试听。
- 原创素材中的三张透明图形由 Agent 编程绘制并栅格化，不能称为图像模型生成。通用 AI 图片/视频生成尚未验证，付费生图 API 方案尚未获得选择，未调用。
- 未试听的音效候选未投入生产；当前成片保留旁白/原声。
- 样本覆盖一个商品与一位采访人物、不同文本长度及三种输出画幅，不构成任意素材的质量保证。字体均衡断行依据字形宽度，不进行语义理解。
- 渲染为本地串行执行；没有分布式吞吐量承诺。技术入库与审美审核仍是两个不同结论，`aestheticQualityVerified` 保持 false。

后续扩充素材、设计新风格或接入生图能力，沿用同一生产与审片流程；无需重新建立批量生产基础设施。
