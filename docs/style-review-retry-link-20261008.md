# 评审布局复用入口补齐（2026-10-08）

试映页已能编辑自定义画布、局部区域及独立变换，但评审卡片的“用这个布局试自己的声音”仍限制为三个标准画幅、30 FPS 和整幅/半幅区域。这使已通过原生校验的 4:3 字幕应用等记录没有复用入口。

## 修改

`style-reviews.tsx` 改用试映页已有的 `trial-layout`、`trial-transform` 和 `trial-text-values` 适配器，完整传递版本、画布/FPS、区域、变换/旋转、文字变量、各层行宽、原视频区域、最短展示时长及语义筛选。Web 仅负责 URL 传输，校验、适配和编译仍由 Rust 执行。无法表达的非字符串文字输入会拒绝生成链接，不会静默删除字段。

独立审查发现试映页会把明确的 `blurredBackground:false` 丢成缺省；虽然视觉相同，Rust 应用指纹及模板 ID 不同。已新增共用 `trial-background` 适配器，路由、表单状态、原生请求、历史捕获/恢复与链接均保留 `undefined / false / true`。复选框仍显示开/关，不增加用户操作负担。

复用入口仅带入这份应用布局；新声音、关键词与标注须在试映页选择。没有把旧素材的输入、保护区或评分继承给新素材，也没有创建或覆盖应用历史。
