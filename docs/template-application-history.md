# 单次应用历史与恢复

模板库版本和具体视频应用分别保存。模板定义风格；应用记录保存某次输入如何使用风格。记录不会自动写项目、渲染成片或给质量评分。

## AI入口

先调用 `dynamic_asset_schema`，读取 `applicationHistorySave`、`applicationHistoryRestore`、`applicationHistoryQuery`。以下说明流程，字段以服务schema为准。

- `list_dynamic_asset_applications({assetId?,contextId?})`：读取记录和各应用上下文的最新head。
- `read_dynamic_asset_application({id})`：读取具体快照、变更与当前可恢复状态。
- `save_dynamic_asset_application({request})`：保存应用及调整理由，返回不可变记录。
- `restore_dynamic_asset_application({id,request:{current}})`：验证目标仍可用，先原子保存当前应用，再返回目标快照及编译投影。调用方恢复其工作台状态；若要改编辑器工程，仍走现有工程编辑协议。

HTTP对应 `/templates/dynamic-assets/application-history` 的GET/POST、`/{id}` GET、`/{id}/restore` POST。Web经 `/api/footage` 代理访问，MCP只透传。

## 调整循环

1. 读取当前样式版本和usageGuide，确定输入版本、语义标注与需要保护的画面；记录来源和不确定性，不将人工标注描述为自动识别。
2. 为一次独立应用分配稳定 `contextId`。改变文字行宽、位置或字号不更换context。读取head；首次保存无parent，此后使用最新head作为 `parentId`。
3. 用原生投影、位置建议和样例验证接口准备应用。先保存基线，再按case调整；记录 `reason`，附实际证据与局限。若需要预览才能保存的完整内容还未准备好，保留本地草稿，不能伪造输入版本。
4. 保存 `application`、组合 `extras`、完整 `samples` 和 `protectedRegions`。保护框另附 `protectionContext:{sample,application,extras}`，明确这些框属于哪个样本和画面构图；`uiState`只是界面恢复数据，不是业务真相。`evidence`是引用和说明，不自动产生评分。每次请求用稳定幂等键；请求内容改变才换键。
5. 查看实际效果与声音，对失败方案继续记录返修或换模板。文案、字体、宽度、比例或画幅变动后重新测量。评分仍使用独立评审协议，应用记录本身不证明泛化或质量。
6. 恢复时传入当前完整状态与当前head；服务拒绝过期目标或有冲突的current，失败时保留现有编辑。成功后恢复目标快照，并使用返回的 `parentIdForNextSave` 继续追加，不能把旧目标ID误当最新head。后续还可以恢复自动生成的备份。

## 一致性边界

同一context的父链使用乐观并发检查。两个Agent或人同时编辑产生冲突时，读取历史并展示差异，不静默取最新head重试覆盖意图。只读历史可保留过期版本；恢复依赖模板、输入和投影仍有效，不能偷偷升级版本重解释旧参数。

工作台内尚未提交的转写、分段或文字草稿先完成/取消再恢复，以免丢失表单状态。已提交到本次应用、尚未写历史的参数和内容作为current备份。跨context恢复须明确选择对应上下文；不会把无关视频混成一条编辑链。

本功能保存调整历史，不替代模板版本历史、项目撤销栈或审美评审。样式指南发生版本变化时也需重新核对应用，不继承旧分数。

## 工作台当前支持范围

标准试映可保存与恢复布局、完整语义/字幕/短语标注、附加样式和保护区。应用历史默认折叠，保持效果预览为主。遇到未提交的转写编辑先完成或取消；当前已提交到试映但尚未写历史的修改会作为恢复前备份。

素材绑定支持“沿用模板默认／替换素材／本次禁用”，完整保留 `enabled:false`，覆盖实时预览、试产、session、JSON和历史恢复。禁用必需素材由原生校验拒绝，UI不另写业务判定。

包含自定义画布或主区域、局部区域与独立缩放组合、叠加样式原始画布严格适配、内容变量、独立事件/声音、译文或按设计绑定素材的记录可完整读取，但当前Web试映不能完整编辑，所以在请求恢复前禁用并提示使用原生Agent工具。不能靠忽略这些字段实现表面恢复。原生恢复仍只返回数据和投影，Agent需要按对应消费端协议应用。

原生 `uiState` 为不透明界面提示；Web仅读取经过结构检查的当前素材、保护区留白和自动分段提示，不能用旧界面数据覆盖权威Sample中非空的字幕分段。
