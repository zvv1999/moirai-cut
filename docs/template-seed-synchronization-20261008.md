# 本地样式与可复用种子同步

发现18份原生模板种子中有11份落后于本地保存定义：时钟缺少最新图层/保持/动作，清单花字缺少当前阅读宽度和同步勾形，双层花字缺少当前排版，其余多份缺使用指南。直接用旧种子初始化不会得到当前已评审设计。

已同步11份，全部18份逐字段对齐当前原生定义（仅revision归零），经Rust inspect规范化往返完全一致。未保存新模板版本、修改Application、继承评分或触碰用户参考工程。

七个旧构造脚本已改为“已有保存版直接使用，缺失才从种子经Rust校验和CAS创建”：清单图标/花字、灯泡图标/花字、增长花字、地球、纸面便签。它们不再从另一款样式复制字段重建旧设计，避免顺带继承不相关使用指南，也不再反写种子。原构造源码保留于本地审计目录。输出目录仍可用PILOT_OUTPUT指定，缺省从当前用户目录解析。

验证：4个传输测试覆盖已有修改保持、缺失创建、校验拒绝、并发创建冲突不升级成覆盖；七个真实已存在资产调用各仅1次GET，前后完整库相同。18份种子原生往返通过；尚未进行全新安装或重新视觉评分。媒体依赖包不在此次18个无绑定原生种子范围内。

工具：`scripts/templates/sync-style-seeds.py`默认为只读检查，选定文件加`--write`才导出；写前统一校验并复读版本。业务校验仍由Rust提供。用法见`./../scripts/templates/seeds/README.md`。

证据：`/Users/zhengwei/Downloads/template-seed-sync-20261008/`的sync.json、verification.json、initializer-readback.json及prior-initializers/。此项补齐设计分发的一致性，不提升任何模板的视觉分数。
