# 字幕短语排版提示：实现约束与验收方案

状态：Rust输入/校验/编译与共享Canvas渲染已实现并通过单测；运行服务已更新，试映内容选择/取消/保存/恢复、AI文档及三份导出已验证。成片属性面板已支持静态文字选区添加/移除/清除及失效提示；双语排版和更全面适配仍待完成。本阶段不代表功能已完整交付，也不替代20个独立样式的质量验收。

## 已确认的问题

中文样例“先选出今天最重要的一件事，”出现“最/重要”的视觉换行。Canvas排版已使用Intl.Segmenter的word粒度，分词结果确实为“先、选出、今天、最、重要、的、一件事、，”。这是语义短语边界缺失，不能靠修复单字切分或加入“最重要”特例解决。

现有Rust `templates/rhythm.rs`分别定义SemanticUnit、CaptionCue、WordSpan和词时间。`events.rs`在确定实例内容后映射keyword_range与word_ranges；`compiler.rs`写出UTF-16高亮范围和相对实例的逐词时间。Web `text/fit-region.ts`负责字体测量、按词换行、居中平衡和字号适配。没有独立的短语排版提示。

## 模型边界

新增的候选输入名称为`layoutPhrases`，每项包含`wordSpan:{startWord,endWord}`；范围为原始对齐词序列上的半开区间，不携带时间。它只表达一组相邻词应优先同排，不定义强调颜色、语义角色、字幕出现时机或动效。

- 语义段仍决定内容意图。
- captionSpans仍决定哪一组词同时显示及对应音频时段。
- keyword仍决定重点内容，可与layoutPhrases不同。
- layoutPhrases由人或内容分析Agent显式提供，原生层验证和映射；前端不加入语义推断。
- 模板样式决定字体、区域、最大行数等；不保存针对某条音频的绝对词下标。

不默认把所有keyword当作不可断行短语：很长的重点句仍需要换行。逐词高亮范围随时间变化，尤其不能直接拿它作换行依据，否则会产生播放过程中的排版跳动。

## 执行契约

1. PlanInput与生产Sample使用同一可选字段，省略保持旧行为；schema与AI能力描述必须同步。
2. Rust验证范围非空、合法、按序且互不重叠，指向当前输入的词。显式样例必须固定transcriptRevision。未知或过期词范围不能静默套用。
3. 提示不合并或拆分CaptionCue，不改原声及词时间。跨显示段的短语给出原生可定位警告，跳过这项提示，不能为了保持短语而暗中延长字幕。
4. 内容绑定到完整包含该范围的显示实例时，Rust按真实拼接结果映射成UTF-16范围；带上精确content用于编辑后的失效检测。翻译或替换文案无法精确对应时不猜范围。
5. 编译参数中的范围是静态内容元数据，禁止关键帧。渲染器仅按当前字体测量优先保持短语，不做中文语义分析。
6. 明示换行优先于提示。一个短语在当前字号下比整行还宽时，回退普通词边界换行，不能为保持短语把整段缩成不可读小字；仍遵守现有行数和高度预算。
7. 内容修改后范围与content不符即失效，不能高亮/绑定到错误位置。不要往可见content插入word joiner、零宽字符或伪造换行来隐藏模型缺口。
8. 模板编辑预览、项目预览与导出共享同一测量实现；保留旧资产和旧工程兼容性。

## 人与AI编辑闭环

内容审核区以词序列选择短语，提供“尽量同排”和取消操作，展示现有短语列表。该操作归内容应用，不混入样式的逐词高亮开关。样式工作台可用示例短语预览效果，但示例范围不写入样式定义。成片编辑器应能查看和取消映射后的范围，手工改文案时明确显示失效状态。不能只加JSON字段后宣称功能闭环。

## 必须完成的验证

- 原生：合法/非法/重叠范围、跨字幕警告、UTF-16表情、英文间隔、中文标点、内容替换、转写revision变化。
- 渲染：保留“最重要”及“交付结果”；长短语退回普通换行；不改变显式换行；同一字幕逐词高亮切换时行布局不动；原文字符与高亮范围保持。
- UI：选择、取消、保存、刷新、人改文案后的失效反馈；AI提交与UI得到同样结果。
- 导出：至少三个已有实测中文输入，固定样式/字号/区域、原声和词时间，对照提示前后导出；查看普通段、短语出现、跨行和短窗口。导出与预览对照，分别记录是否试听。
- 不将文字区域单测、字段存在或技术导出当作90分审美完成。

## 实施顺序

先添加原生可选输入、验证和映射测试，再接共享渲染及回退测试，随后补内容选择与AI契约，最后用原有中文样例实际导出对照。避免只做某一个样例的手工字幕补丁。
