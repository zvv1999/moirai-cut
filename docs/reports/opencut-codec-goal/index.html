05 / AGENT

人和 Agent，操作同一条生产链

Agent 调用不绕开编辑器状态，也不生成不可追踪的旁路文件。媒体诊断、代理开关、批量重建、交付、取消、重试与结果查询都复用同一作业模型和校验语义。

READmedia.probe只读返回媒体事实与兼容性
PROXYensureProxy幂等创建或复用代理作业
BATCHrebuildProxies受控并发，逐素材结果
STATEsetProxyEnabled与人工 UI 使用同一状态路径
DELIVERmedia.transcode验证过的预设与作用域路径
