T08 · RIPPLE PREVIEW DONE

Ripple 的连锁结果在松手前就发生

首镜头右边缘缩短 1.00s 时，HUD 同时显示播放头吸附与“后续 22 个镜头”影响范围，时间线用最终命令相同的算法预移动所有受影响片段。Escape 丢弃预览后，工程边界和轨道数完全不变。

T08 · MOVE & DROP FEEDBACK DONE

落点、吸附和冲突不再靠猜

移动 HUD 持续显示目标时间与目的轨道；进入冲突区时明确说明会新建兼容轨道，非法落点说明松手将取消。拖动中的片段以抬升阴影和半透明状态与原时间线区分。

T06 · TIMELINE SNAPSHOTS DONE

恢复前先看清楚会改变什么

真实工程保存了命名基线，把两个片段临时合成为复合片段，再得到 Add 2 / Remove 1 的结构化差异和逐项说明。恢复需要二次确认并校验当前 revision；完成后以新版本向前推进，原始两个片段返回，临时复合片段消失。

T05 · COMPOUND CLIPS DONE

嵌套保留真实素材与相对节奏

两段真实素材被装入 3.80s 容器，内部仍可逐项改名和以 0.1s 调整相对位置；刷新后结构保留，渲染器在预览与导出时递归展开子片段。拆解与全局撤销/重做共用命令历史，最终工程已恢复原始剪切点。

T04 · EDIT-POINT TRANSITIONS DONE

转场现在是可管理对象，而不是一次性关键帧配方

真实工程把 0.50s 交叉淡化替换为 0.55s 淡黑转场，刷新后类型、时长和稳定地址仍保留。持续时间滑杆、细调、替换、移除与全局撤销/重做共用命令历史；非相邻素材会在变更前给出明确原因。

T03 · MARKERS & RANGES DONE

标记既是人的注释，也是 Agent 的稳定地址

管理器同时展示片段范围与时间线标记的名称、颜色、时间、作用域和 ID 前缀。真实工程验证了备注、前后导航、刷新持久化，以及删除后的全局撤销/重做；MCP 与页面操作均支持按稳定 ID 更新。

T02 · GROUPS & LINKS DONE

T01 · SELECTION SYSTEM DONE

真实工程中 Shift 按时间顺序跨文本、主视频和音频轨选出六个片段；Command 只切换目标片段；拖框再次跨三类轨道得到六项。状态条持续显示选择数量和操作提示，每个片段同时暴露可访问的选中状态。

M07 · DUPLICATE REVIEW DONE
