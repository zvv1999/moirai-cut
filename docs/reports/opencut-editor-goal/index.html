W08 · PRECISION TRIM DONE

五类修剪语义可见、可用、可撤销

Standard、Ripple、Roll、Slip 与 Slide 常驻时间线上方，并根据真实片段与相邻关系解释可用性；Roll 保持相邻片段总时长，Slide 同步滚动两侧剪切点，所有位移按项目帧率对齐并进入统一撤销历史。

W07 · TRACK CONTROLS DONE

轨道身份、能力与状态终于在同一处可见

每条轨道直接显示名称与可接收素材类型，并提供锁定、独奏、静音或显隐、轨高和删除；五类新增入口常驻，重命名和轨高变更均进入统一撤销历史。

W06 · MODE STATUS DONE

编辑模式不再依赖猜图标和悬停

磁吸、波纹和源音频关联状态以文字常驻显示；选中真实视频后可直接分离并恢复源音频，快捷键与 Shift 临时绕过提示也始终可见。

W05 · NAVIGATION DONE

局部精修与全局位置同时可见

鼠标锚点缩放不会丢失关注位置；常驻总览条可点击或拖拽跳转，适配与定位播放头入口在窄屏下仍可见，横向滚轮也能稳定浏览长工程。

W04 · PLAYBACK DONE

逐帧、变速、循环和预览性能可直接控制

所有播放动作都保持可见并有明确名称；逐帧移动对齐项目帧率，变速同步音频调度，循环可在尾点携带余量回绕，Performance 模式则在播放时降低预览渲染频率。

W03 · KEYFRAMES DONE

人工关键帧操作形成完整闭环

属性行可前后跳转、在播放头增删并反馈当前状态；选中关键帧后可按帧移动、复制粘贴、切换插值并打开曲线编辑器。

W03 · MULTI-SELECT DONE

轨道内可见、可多选、可精确调整

关键帧轨道可展开或收起；点击、组合键和框选可建立多选集合，并由统一动作栏完成一帧移动、复制、粘贴、插值和删除。

W02 · INSPECTOR DONE

选中了什么，一眼可见

真实视频片段被选中后，检查器固定保留名称、类型、时长和轨道；六个命名属性分组可直接切换，每个属性都有一致的重置与关键帧入口。

W01 · OFFLINE DONE

丢失状态不会静默

真实时间线图片被临时移出媒体目录后，素材库、时间线和当前播放头画布同时进入一致的红色离线状态，并给出明确重链接入口。

W01 · RELINKED DONE

重链接保留全部剪辑

从界面选择原文件后复用同一 mediaId，素材数恢复 44，画布立即恢复；变换、裁边和 4 个关键帧保持不变，文件哈希一致。

M02 · W06 · T07 GREEN

编辑模式可被识别

素材面板、当前选择、编辑模式、快捷键提示和时间线处于同一工作台上下文，图标按钮具备可访问名称。
