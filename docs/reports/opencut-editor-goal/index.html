V02 · COLOR & LUT DONE

曝光、对比度、色温、饱和度、高光、阴影和曲线形成统一处理链；严格解析 .cube 文件并以可调强度三线性采样，预览与导出共用实现。

V03 · ADJUSTMENT LAYER DONE

一条调节层可统一覆盖下方画面

效果轨上的调节层只处理时间覆盖内、位于其下方的兼容视觉层；上方内容和非视觉背景不被误处理，参数仍可随时回改。

V04 · MASK STACK DONE

蒙版从单个限制升级为可组合栈

内置和自由蒙版可按顺序 Add、Intersect、Subtract 或 Exclude；每个蒙版保留反转、羽化、描边、关键帧与画布手柄。

C01 · AUTOMATIC TRANSCRIPTION DONE

转写成为可恢复的编辑任务

可选择全时间线或当前选区，过程显示进度并允许取消；失败保留明确原因和 Retry。无选区验证会在下载模型或处理音频前安全停止。

C02 · SPEAKER & WORD TIMING DONE

说话人与逐词时间不会在导入后丢失

转写请求真实 word timestamps，并保留说话人元数据；只有 cue 级时间的外部字幕也能一键生成可编辑逐词时间，本次验收生成并编辑了六个词。

C03 · BULK TEXT EDITING DONE

字幕校对从逐条返工变成批量流程

搜索替换、多选、重复词与双空格清理、整体移时共用一个可撤销模型。验收将 Listen 批量改为 Stay，并把三条 cue 安全后移 0.2 秒。

C04 · GLOBAL CAPTION STYLES DONE

字幕样式成为工程资产

样式随项目保存，可创建、更新、复制、批量应用或分离；样式和时间线写入都经过撤销历史。浏览器验证完成 Reed Bilingual 的应用、分离和撤销。

C05 · BILINGUAL CAPTIONS DONE

双语不是简单拼成一段文字

主副文本共享 cue 时间，但使用独立布局、字号和颜色；渲染器按组合边界计算背景和换行。验收画面中副字幕以青色和更小字号单独呈现。

C06 · CAPTION QUALITY DONE

字幕问题在导出前可见

检查器覆盖过长行、危险位置、重叠、异常间隙、过短时长、CPS 阅读速度和工程边界，并直接关联到 cue，避免把结构问题留到成片。

C07 · CAPTION INTERCHANGE DONE

字幕可进可出，并说明格式损失

文件选择和粘贴源都支持 SRT、VTT、ASS；导出保留各格式能表达的信息，并明确提示 SRT 无法保存说话人与可复用样式等限制。

A01 · VOLUME ENVELOPE DONE

音量曲线现在可以直接在片段上编辑

包络线和关键帧覆盖在真实波形上，可直接增加节点并同时拖动时间与 dB。验收把 1.20s / −2.0dB 拖到 2.77s / −11.1dB，播放头跟随节点，检查器同步显示 −11.1；最终工程已恢复原关键帧。

A02 · AUDIO FADES DONE

淡入淡出拥有同一套实时状态

时间线手柄、遮罩斜线和数值字段共享预览感知元素；输入数值会移动手柄，反向拖动也会更新检查器。窗口级指针生命周期避免重渲染中断拖拽，嵌套按钮导致的两条水合 Issues 已归零，验收后 Fade In 已持久化恢复为 0。

A03 · LOUDNESS & PEAKS DONE

标准化先看峰值余量，再决定增益

46.3 秒真实 WAV 在浏览器本地测得 −23.6 LUFS 与 −1.5 dBFS。目标差距虽有 9.6 dB，工作台仍按峰值上限建议 +0.5 dB，并把削波警告和“源文件不被改写”写在操作旁；写入后可由同一命令历史完整撤销。

A04 · SOURCE AUDIO DONE

分离时写入稳定来源地址；恢复会把音量、动画与处理参数带回视频，并只删除对应生成伴音。真实工程验证时间线音频片段从 1→2→1，残留伴音为 0；若伴音已经发生时间漂移，界面会阻止恢复而不是静默丢编辑。

A05 · PROCESSING CHAIN DONE

预览与导出共用一条非破坏处理链

降噪、人声增强、声道平衡和独立处理增益都保存在片段参数中；实时播放通过 Web Audio 节点，最终混音走相同设置。真实工程连续启用两项处理后分别撤销，持久化参数精确回到基线。

A06 · WAVEFORM CACHE DONE

A07 · INPUT & COUNT-IN DONE

设备和准备节奏在录音前就能确认

A07 · VOICE-OVER DONE

T08 · RIPPLE PREVIEW DONE

T06 · TIMELINE SNAPSHOTS DONE
