# 模板开发脚本索引

本目录保留模板开发期间使用的初始化、素材处理、生产、测量和回归脚本。
Rust 原生模型与执行器是业务规则的来源；这里的脚本是调用工具和历史实验记录，
不能把某次样片的坐标、时间或评审结果当成模板的通用规则。

## 从哪里开始

| 需求 | 入口 | 边界 |
| --- | --- | --- |
| 理解当前源码与验证状态 | [工作检查点](../../docs/template-work-checkpoint-20261020.md) | 区分代码能力、历史证据与待办 |
| 初始化缺失的可复用样式 | `initialize-style-seed.mjs`、[seeds/README.md](seeds/README.md) | 已保存设计优先；缺失时经 Rust 校验和版本检查后创建 |
| 核对种子与当前库 | `sync-style-seeds.py` | 默认只检查；`--write` 仅更新指定仓库文件，不改素材库 |
| 通过 AI 批量生产 | `../../apps/mcp/src/template-production.mjs`，根目录 `bun run templates:produce` 接 `--batch` / `--manifest` / `--designs` 参数 | 参数与流程见 [生产说明](../../docs/template-production.md)；实际执行会创建任务 |
| 运行自动化回归 | 根目录 `bun test`、`bun run test:mcp`、`cargo test --locked -p moirai-footage --all-targets` | 不等价于真实素材、模型、浏览器和听感验收 |

初始化工具是供 authoring 入口调用的模块，不是执行一次就初始化整个模板库的 CLI。
种子只保存原生 Definition；应用记录、文案标注、成片和分数不随种子转移。

## 文件类别

| 文件名模式 | 用途 | 使用前需要确认 |
| --- | --- | --- |
| `author-*`、`draft-*`、`refine-*`、`edit-*` | 创作或迭代某个设计 | 是否会保存或覆盖已有版本；优先保留当前已保存设计 |
| `produce-*`、`submit-*`、`run-*` | 生产编排、提交任务与生成样片 | 输入素材、服务地址、任务输出位置，以及是否调用模型 |
| `prepare-*`、`import-*`、`build-*` | 准备插画、字体或输入数据 | 素材来源、授权、路径和生成目标 |
| `verify-*`、`check-*`、`audit-*`、`validate-*` | 契约、交互或视觉回归 | 名字不代表只读；部分脚本会创建工程、改样式、导出或写评审 |
| `measure-*`、`compare-*`、`diagnose-*`、`inspect-*`、`probe-*` | 测量与差异定位 | 测量对象的文案、版本、画幅和应用身份 |
| `review-*`、`publish-*`、`save-*`、`archive-*`、`export-*`、`reexport-*` | 保存证据、发布评审或导出结果 | 是否写入库记录，以及证据是否属于当前设计和当前输入 |
| `seeds/*.json` | 可复用定义种子及历史策略数据 | 具体文件类别见种子说明；JSON 不自动构成成片验收 |

带有日期、样式名、样片名或版本后缀的文件通常服务于当时的一次验证。
保留原文件名以维持文档引用与脚本间导入关系，不将它们统一串成安装流程。

## 运行约定

1. 先阅读目标脚本，确认其输入、输出和写操作。不要通配执行整个目录。
2. 部分历史脚本包含本机绝对路径、项目 ID、端口或字体名称；在另一台机器上
   需要显式提供对应夹具和运行环境。它们不是开箱即用的公共样例集。
3. 初始化器和种子同步器支持 `WORKBENCH_URL`；其他脚本的配置方式以各自源码为准。
4. 写入遵循服务端 revision / idempotency 协议。单次应用调整保存在 Application / Sample，
   不能为了某个样片通过而隐式覆盖 Definition。
5. 媒体、数据库、运行日志和验收视频留在本机输出目录。Python 缓存与生成的 WASM 包
   已由根目录 `.gitignore` 排除。
6. 评审需要匹配当前设计、输入、编排和渲染结果。历史报告与单次数字评分
   不能代替新的画面及声音验收。

## 维护方向

稳定的业务行为和校验应沉淀到 Rust 及其测试；Web/MCP 只保留交互与平台适配。
重复实验优先复用初始化器、原生接口和共享的测量契约。尚未统一配置的历史脚本
保留为开发资料，后续按实际使用频率整理成可参数化入口。
