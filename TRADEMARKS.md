# Moirai Cut trademark and brand policy

The source code in this repository is licensed under the MIT License. That
license does not grant permission to use the Moirai Cut name or visual marks in a
way that implies sponsorship, endorsement or an official release.

## Allowed uses

You may:

- truthfully state that software is compatible with, built for, or derived from
  Moirai Cut;
- use the name and unmodified logo to link to the official project;
- use the marks in news, reviews, tutorials, academic work and community events;
- describe a fork as “based on Moirai Cut” when the fork has a distinct name and
  visual identity.

## Uses that require maintainer permission

Please ask before using the Moirai Cut name or logo for a company, product, hosted
service, paid course, merchandise, domain name or event where people could
reasonably believe it is official.

## Not allowed

Do not:

- present a modified build or hosted service as an official Moirai Cut release;
- register confusingly similar product names, domains or social accounts;
- modify the logo in a way that weakens attribution or creates a false
  endorsement;
- use upstream OpenCut, CapCut, Jianying, OpenAI, Anthropic or other third-party
  marks as Moirai Cut branding.

This is a project policy, not a statement that a trademark has been registered
in every jurisdiction. Maintainers should complete professional name and
trademark clearance before a public launch in target markets.
